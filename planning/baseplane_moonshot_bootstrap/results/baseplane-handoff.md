## Qualification handoff

[Q01–Q05](../machine/deferred-qualification.json) remain document obligations,
unscheduled by this workshop:

- **Q01:** general CPU/CUDA semantics, differential/adversarial checks, stable and unordered outputs, sanitizers and public API audit.
- **Q02:** end-to-end costs including sequence packing, construction, routing, upload, detail/replay, bytes and information loss; cold/reused workload comparisons.
- **Q03:** inspected current Cellerator producer/runtime interfaces and optional Torch views; no obsolete adapter resurrection.
- **Q04:** explicit biological objective, suitable held-out units, leakage/non-identifiability analysis and fixed/local/dense/learned baselines.
- **Q05:** separately authorized distribution/persistence only when a concrete need is established; account for communication and invalidation.

The intended destination is useful learned hierarchical sequence context. This
workshop supplies competing runnable pieces and connected bounded paths toward it;
a whole-genome hierarchy, biological usefulness, performance advantage and
production readiness remain unestablished.
