# Composition measurements deferred

The focused host composition consumer records no timing or benchmark claim.
Preparation copies/packs the source, fits caller-supplied model parameters before
construction, builds two hierarchy alternatives and a 2-base posting index.
Execution scans predicate support, computes a hierarchy response, encodes routes,
revisits requested exact support and counts global nonlocal pairs. Edits repair
incremental values/postings and explicitly rebuild derived representations.

Any future assigned benchmark must measure preparation, model fitting, query
support scans, output capacity/materialization, routing and edit/rebuild costs.
GPU resources and framework/provider packaging remain outside this example.
